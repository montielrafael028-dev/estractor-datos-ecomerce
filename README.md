# Estractor Automatico de Productos y Precios (Web Scraper)
Este proyecto es una herramienta comercial desarrollada en **Python** utilizando el entorno **Thonny** su objetivo es automatizar la recolección de datos de tiendas de productos de comercio electronico, optimizando el tiempo de analisis de competencia de gestión de inventarios para negocios digitales.
## Problemas que resuelve
monitorear los precios de la competencia manualmente consume horas de trabajo y genera errores de digitación. Estes script automatizado reduce ese proceso a **menos de 5 segundos** entregando información precisa y estructurada. 
## características del software
* **Conexión segura:** Implementa simulación de navegación (User-Agent) para evitar bloqueos por parte del servidor.
* **Extracción Inteligente:** Identifica titulos y precios aislando las etiquetas de HTML mediante 'BeautifulSoup'.
* **Limpieza de datos:** Aplica logica de cadenas en Python para remover caracteres extraños de codificación en las divisas.
* **Exportación  Automatizada:** Genera un reporte limpio en formato '.csv' compatible con Microsoft, Excel y Google sheets.
## Tegnologías utilizadas
* Python 3
* Requests (Conectividad HTTP)
* BeautifulSoup4 (Análisis e interpretación HTML)
* CSV (Manejo y estructuración de archivos de datos)
